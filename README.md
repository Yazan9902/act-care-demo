# ACT Care — live prototype

Published build of the ACT Care UI prototype for ACT Medical Ltd.

**Open it:** https://yazan9902.github.io/act-care-demo/

Sign in with any of the four people on the landing screen — there is no password.
Pick **Monir** for the operations view, or **Ihab** to see the field engineer's
app with every commercial figure removed.

All data in this build is invented. The customer names are real ACT customers,
but every serial number, ticket, contract value and warranty date is fabricated
demo data. Nothing here is a record of real equipment or real service work.

Source lives in the private `act-care` repository. This repository holds only the
compiled single-file build.
